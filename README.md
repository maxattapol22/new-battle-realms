# New Battle Realms

เกม RTS สั้น ๆ แนว Battle Realms เปิดด้วย Google Chrome บนมือถือหรือคอมพิวเตอร์ ดับเบิลคลิก `index.html` ได้เลย

## วิธีเล่น

1. เลือกเผ่า: มังกร (จีน), เสือ (เกาหลี), นกอินทรีย์ (ญี่ปุ่น), ช้าง (ไทย)
2. กด «ข้าวทั้งหมด» หรือ «น้ำทั้งหมด» ให้ชาวนาหญิงเก็บทรัพยากรแล้วเดินกลับคลังเอง
3. กด «ไม้ทั้งหมด» ให้ชาวบ้านชายตัดต้นไม้ ไม้ใช้สร้างหอฝึก ยุ้งข้าว และบ่อน้ำ จากนั้นแตะจุดบนแผนที่
4. แต่ละเผ่ามีหัวหน้าหมู่บ้าน 1 คน กด «หัวหน้า» แล้วส่งเขาเข้าหอฝึก เขาจะกลายเป็นหัวหน้านักรบ ทหารที่ยืนใกล้จะโจมตีแรงขึ้น ชาวบ้านชายคนอื่นฝึกเป็นทหารธรรมดา
5. กด «เลือกทหาร» แล้วแตะศัตรูหรือพื้นที่เพื่อบุก
6. ลากพื้นที่ว่างเพื่อเลื่อนกล้อง หรือแตะแผนที่มุมขวาเพื่อกระโดดไปจุดนั้น
7. ทำลายศูนย์กลางของศัตรูให้ได้ก่อน

แต่ละเผ่ามีโบนัสและหน่วยไม่เหมือนกัน ช้างศึกทำความเสียหายกับอาคารได้มาก ทรัพยากรคือข้าว น้ำ และไม้ ประชากรสูงสุด 20

## ภาพตัวละคร (สำหรับคนทำเกม)

- เผ่ามังกรใช้ภาพตัวละครจริง เดินและยืนได้ 8 ทิศ เผ่าอื่นยังวาดเป็นรูปทรงจนกว่าจะมีภาพ
- ภาพต้นฉบับอยู่ใน `assets/<เผ่า>/` ส่วนเกมโหลด atlas ที่ย่อแล้วจาก `assets/<เผ่า>/atlas/` กับ `assets/sprites.js` (เล็กกว่าต้นฉบับราว 50 เท่า)
- เพิ่มหรือแก้ภาพแล้วให้รัน `python tools/build_sprites.py` (ต้องมี Python กับ Pillow)
- เพิ่มท่าโจมตีจาก Grok: `python tools/import_attack.py <ภาพ> <ตัวละคร> <ทิศ>` สคริปต์จะสร้าง atlas ให้เองด้วย prompt ทั้ง 40 ภาพอยู่ใน `tools/attack_prompts.md`
- ตัวละครที่ยังไม่มีท่าโจมตีจะพุ่งตัวพร้อมเอฟเฟกต์ฟันแทน พอมีภาพท่าโจมตีของทิศนั้น เกมจะสลับไปใช้ภาพเอง
